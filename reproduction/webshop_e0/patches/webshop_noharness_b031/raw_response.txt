The failure pattern is that the agent sometimes reaches a product detail page and tries to buy the item even though the page still has a required variant choice unselected, such as color, size, material, flavor, style, or count. In WebShop this can cause an invalid purchase attempt or prevent the agent from completing the task, so the harness should intervene at the moment the buy action is about to be taken rather than after the fact.

The hook runs in on_before_action and only inspects click actions whose normalized value is buy now. It maps runtime predicates to that action: if product_price_over_budget is true, it blocks the purchase and prompts the agent to return to search or results for an in-budget item. If required_options_unselected is true, it blocks buy now and tells the agent to choose the matching visible option first, or go back to search if no matching option is available. This keeps normal browsing and selection behavior unchanged, but prevents an otherwise recoverable premature purchase from turning into a failed episode.
