The failure pattern is that the agent sometimes reaches a product detail page and tries to buy the item even though the page still has a required variant such as color, size, material, flavor, style, or count unselected. In WebShop this can cause an invalid purchase attempt or a wrong item to be bought, so the harness should intervene at the moment the Buy Now click is about to be taken rather than after the action has already been submitted.

The hook runs in on_before_action and only inspects click actions whose normalized value is Buy Now. It maps runtime predicates to two checks: if product_price_over_budget is true, it blocks the purchase and prompts the agent to return to search or results for an in-budget item; if required_options_unselected is true, it blocks Buy Now and tells the agent to choose the matching visible option first, or go back to search if no matching option is available. This keeps normal browsing and buying behavior unchanged except for the unsafe premature purchase attempt.
