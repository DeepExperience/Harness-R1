The failure pattern is that the agent sometimes reaches a product detail page and tries to buy the item even though the page still has a required variant such as color, size, material, flavor, style, or pack count unselected. In WebShop this can cause an invalid purchase attempt or prevent the model from completing the task, because the correct item is not actually chosen until the visible option matching the instruction is clicked. The harness should intervene at the moment the agent attempts to use Buy Now, since that is the point where an otherwise recoverable option-omission error becomes a failed purchase action.

The hook runs in on_before_action and only inspects click actions whose normalized value is Buy Now. It maps runtime predicates to the needed behavior: if product_price_over_budget is true, it blocks the click and prompts the agent to return to search or results for an in-budget item. If required_options_unselected is true, it blocks Buy Now and gives a targeted prompt to choose the matching visible option before buying, with a fallback instruction to go back if no matching option is available. This keeps normal browsing and option selection unchanged, but prevents the model from submitting a product that has not yet been configured to satisfy the task constraints.
