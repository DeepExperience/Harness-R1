The failure pattern is that the agent sometimes reaches a product detail page and tries to buy the item even though the page still has a required variant such as color, size, or material unselected. In WebShop this can cause an invalid purchase attempt or a wasted turn, so the harness should intervene at the moment the buy action is about to be taken rather than after the environment has already treated it as a purchase.

The hook runs in on_before_action and only inspects click actions whose normalized value is buy now. It maps runtime predicates to that action: if product_price_over_budget is true, it blocks the buy and prompts the agent to return to search or choose an in-budget item; if required_options_unselected is true, it blocks the buy and prompts the agent to choose the matching visible option or go back if no matching option is available. This keeps normal browsing and selection behavior unchanged, but prevents an otherwise recoverable premature purchase from being submitted.
