The failure pattern is that the agent sometimes reaches a product detail page and tries to buy the item even though the page still shows required variant choices such as color, size, material, flavor, or width. In WebShop this can turn an otherwise recoverable browsing step into a failed purchase, because the item cannot be completed until the correct option is selected. The harness should intervene at the moment the agent attempts to click Buy Now, since that is the point where an unselected required option becomes a concrete wrong action.

The hook runs in on_before_action and only inspects click actions whose normalized value is Buy Now. It maps runtime predicates to two checks: if product_price_over_budget is true, it blocks the purchase and prompts the agent to return to search or results for an in-budget item; if required_options_unselected is true, it blocks Buy Now and tells the agent to choose the matching visible option or go back if no matching option is available. This keeps normal search and selection behavior unchanged, but prevents the premature purchase action that the observed failures show.
