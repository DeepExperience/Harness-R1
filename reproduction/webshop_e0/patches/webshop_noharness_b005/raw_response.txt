The failure pattern is that the agent sometimes reaches a product detail page and tries to buy the item even though the page still shows required variant choices that have not been selected. In WebShop this can cause an invalid purchase attempt or prevent the model from choosing the correct color, size, material, scent, flavor, count, or pack option that the instruction requires. The harness should intervene at the moment the model attempts to click Buy Now, because that is the point where an unselected required option would turn a recoverable browsing step into a failed purchase.

The hook runs in on_before_action and only inspects click actions whose normalized value is Buy Now. It maps runtime predicates to two checks: if product_price_over_budget is true, it blocks the click and prompts the agent to return to search or results for an in-budget item; if required_options_unselected is true, it blocks Buy Now and prompts the agent to choose the matching visible option or go back if no matching option is available. This keeps normal search and inspection behavior unchanged, but prevents the specific premature purchase action that the observed failures show.
